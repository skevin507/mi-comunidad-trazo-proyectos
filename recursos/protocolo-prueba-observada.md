# Protocolo de prueba observada

**Para qué sirve:** comprobar si una persona nueva puede usar una herramienta o un prototipo **sin que le expliquen**, y encontrar dónde se confunde. Sirve para Trazo Proyectos y para cualquier app, página o guía de la comunidad.
**Duración:** 20 a 30 minutos por persona.
**Necesitas:** la herramienta lista, esta hoja y alguien que observe y anote.

## Origen

Dos pruebas quedaron pendientes por la misma razón: nadie había escrito **cómo** hacerlas. Una fue la del prototipo MakeralDia del grupo 3 del curso (Reto 2). La otra, las pruebas con personas reales de Trazo Proyectos, que su plan de mejoras deja para la última fase. Este protocolo junta lo que ambas necesitaban.

## Reglas para quien observa

- **No ayudes.** Si la persona pregunta, responde: «¿Qué harías tú?». Solo intervén si lleva más de 2 minutos bloqueada, y anótalo.
- Pide que **piense en voz alta**: «Cuéntame qué estás buscando».
- Anota lo que hace, no lo que tú crees que piensa.
- No guardes nombres, correos ni fotos de la cara. Usa «Persona 1, Persona 2».

## Tareas (ejemplo con Trazo Proyectos)

Lee cada tarea en voz alta y anota el resultado:

| # | Tarea | ¿Lo logró sola? (sí · con ayuda · no) | Tiempo | Dónde dudó |
|---|---|---|---|---|
| 1 | Entra a la web y crea un proyecto con una idea tuya | | | |
| 2 | Encuentra cuál es tu siguiente paso | | | |
| 3 | Marca una tarea y escribe su respuesta | | | |
| 4 | Revisa algo que propuso Trazo y decide si lo aceptas | | | |
| 5 | Descarga el PDF del proyecto | | | |

Para otra herramienta, cambia las tareas por 3 a 5 acciones que una persona nueva debería poder hacer.

## Al terminar (5 minutos)

Pregunta:
1. ¿Qué fue lo más fácil?
2. ¿Dónde te sentiste perdida o perdido?
3. ¿Lo usarías otra vez? ¿Para qué?

## Qué hacer con los resultados

- Si **2 o más personas** dudan en el mismo lugar, es un problema real: abre un Issue con lo observado.
- Anota la prueba en la [bitácora](../docs/bitacora.md): qué esperabas, qué pasó y qué cambiarás.
- Repite la misma tarea después del cambio para comprobar si mejoró.
