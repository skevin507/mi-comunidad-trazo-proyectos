# Ficha del Show & Tell

**Para qué sirve:** organizar un encuentro corto en el que cada persona muestra un proyecto **sin terminar**, cuenta qué problema tuvo y pide la ayuda que necesita. Al final quedan compromisos anotados.
**Duración:** 45 a 90 minutos, según cuántas personas presenten (unos 5 minutos cada una).
**Para quién:** cualquiera que quiera anfitrionar. No se necesita experiencia.

## Origen

Viene del ensayo de Show & Tell del **22 de octubre de 2026** en el curso, registrado en el [Reto 4](https://github.com/Universidad-Cenfotec/SINT-741-Curso-Activadores/pull/83). Ahí vimos dos cosas:

- Mostrar trabajos inconclusos y hablar de errores **redujo la presión** y abrió la conversación.
- Faltó tiempo para preguntas y **no quedó registro de los compromisos**. La propuesta de ese registro fue «preparar un formulario breve con el nombre del proyecto, su estado, su mayor obstáculo y la ayuda que busca».

Esta ficha es ese formulario, más una pauta para conducir el encuentro.

## 1. Antes (anfitrión, 15 minutos)

Pide a cada persona que complete esto antes del encuentro:

| Pregunta | Respuesta |
|---|---|
| Nombre del proyecto | |
| ¿En qué etapa está? (idea · probando · casi listo) | |
| ¿Qué voy a mostrar? (pantalla, objeto, boceto) | |
| Mi mayor obstáculo ahora | |
| La ayuda que busco | |

Ordena los turnos y nombra a una persona que lleve el tiempo y a otra que tome notas.

## 2. Durante

**Pauta para quien presenta (3 preguntas, 3 minutos):**
1. ¿Qué estoy haciendo?
2. ¿Qué problema tuve?
3. ¿Cuál es mi siguiente paso?

**Pauta para el grupo (2 minutos por proyecto):** una pregunta o una oferta de ayuda concreta. Ejemplos: «¿Probaste…?», «Yo sé hacer…, te muestro».

**Reglas:** se muestra lo que hay, aunque esté roto. Se comenta el trabajo, no a la persona.

## 3. Al cierre (10 minutos)

Completa la tabla de compromisos a la vista de todos:

| Quién | Se compromete a | Con ayuda de | Para cuándo |
|---|---|---|---|
| | | | |

Si nadie se ofrece para algo, anótalo como «pendiente de ayuda»: así se ve y no se pierde.

## 4. Después

- Sube la tabla de compromisos a la [bitácora](../docs/bitacora.md) o a un Issue.
- En el siguiente Show & Tell, empieza revisando esos compromisos.
- Si de una conversación salió algo que otra persona podría reutilizar, propónlo como recurso nuevo.
